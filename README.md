# Многостраничный сайт на React (Wireframe / Серый прототип)

Стартовая заготовка **многостраничного** сайта в нейтральном сером стиле.
Сделана как «скелет»: страницы и блоки собраны из готовых секций, но без сложной
логики, без `useEffect` и без сторонних библиотек навигации. Всё, что нужно —
менять тексты и цифры в коде.

## Быстрый старт

```bash
npm install
npm run dev
```

Терминал покажет ссылку (обычно `http://localhost:5173`) — откройте её в браузере.
Правки в коде обновляются на странице мгновенно.

Другие команды:

```bash
npm run build     # собрать сайт в папку dist
npm run preview   # посмотреть собранную версию
npm run lint      # проверить код линтером
```

## Как устроен проект

```
src/
├─ App.jsx               ← карта страниц (какой ключ = какой компонент)
├─ App.css               ← внешний вид: цвета, сетки, отступы
├─ index.css             ← базовый сброс стилей
├─ router/
│  ├─ navigation.js      ← контекст и хук useNavigation()
│  └─ NavigationProvider.jsx ← хранит открытую страницу (useState, без useEffect)
├─ data/
│  ├─ site.js            ← название, меню, контакты, подвал
│  └─ content.js         ← тексты: услуги, проекты, команда, отзывы, FAQ, цены
├─ components/           ← блоки-секции (шапка, подвал, hero, карточки и т.д.)
└─ pages/                ← страницы, собранные из блоков
```

## Как менять значения

Всё, что нужно править, лежит в двух файлах — **`src/data/site.js`** и **`src/data/content.js`**.
Компоненты лишь показывают эти данные, поэтому внешний вид подстроится сам.

Например, чтобы добавить услугу, допишите объект в массив `services`:

```js
export const services = [
  // ...
  { tag: 'Новое', title: 'Мой сервис', text: 'Описание услуги.', price: 'от 10 000 ₽' },
];
```

## Как добавить новую страницу

1. Создайте компонент в `src/pages/` (проще всего скопировать существующий).
2. Импортируйте его в `src/App.jsx` и добавьте строку в объект `PAGES`:

   ```js
   const PAGES = {
     // ...
     blog: BlogPage,
   };
   ```

3. Добавьте пункт меню в `src/data/site.js`:

   ```js
   nav: [
     // ...
     { key: 'blog', label: 'Блог' },
   ],
   ```

Ключ в `PAGES`, `key` в меню и ссылки в подвале должны совпадать.

## Как работает навигация

Навигация — это **одно значение `useState`** в `NavigationProvider`.
Переход делается функцией `go('services')`, которую отдаёт хук:

```jsx
import { useNavigation } from '../router/navigation';

const { page, go } = useNavigation();
go('contacts'); // открыть страницу «Контакты»
```

`useEffect` нигде не используется. Переключатель страниц не меняет адрес в браузере
(это макет), поэтому перезагрузка страницы возвращает на главную.

## Как перекрасить сайт

Все цвета собраны в переменных в начале `src/App.css`:

```css
:root {
  --c-900: #18181b; /* самый тёмный */
  --c-800: #27272a;
  /* ... */
  --c-50:  #fafafa; /* самый светлый */
}
```

Меняйте их — и весь сайт перекрасится сразу.

## Полезные советы

1. **Как вставить картинку?** Положите файл в папку `public/` (например, `photo.jpg`)
   и используйте `<img src="/photo.jpg" alt="Описание" />`. Любую серую заглушку
   с текстом `[ Картинка ]` можно заменить на реальное изображение.
2. **Формы ничего не отправляют.** В `Calculator.jsx` и `ContactForm.jsx` стоит
   `event.preventDefault()` и комментарий — подключите отправку там.
3. **Перед сдачей работы** уберите тексты в квадратных скобках вида `[ Название проекта ]`.
4. **Не бойтесь ломать!** Если появилась ошибка — в терминале и браузере будет
   номер строки, где вы ошиблись.
